# Contributing

Contributions should improve portability, safety, and operational clarity without adding organization-specific confidential information.

## Pull request checklist

- [ ] Every display name starts with `[CS STANDARD]`.
- [ ] No real names, private URLs, IDs, credentials, customer data, or raw communications are included.
- [ ] New placeholders use `[UPPER_SNAKE_CASE]` and are documented.
- [ ] Required and optional capabilities are clearly separated.
- [ ] Facts, inferences, recommendations, and unknowns remain distinguishable.
- [ ] The template includes missing-data, conflicting-data, and permission-failure behavior.
- [ ] Customer-facing and internal-only information remain separated.
- [ ] The template has been tested with synthetic data.

Do not add screenshots or copied examples unless they have been independently approved for public redistribution.
